# C Programming — Exercise

They are a set of C programs written to practice core programming concepts, as part of my Computer Science coursework at Kirinyaga University.

## Files
- `CAT2_Q1.c` — Math-based problem solved using C
- `CAT2_Q2.c` — Math-based problem solved using C
- `CAT2_Q3.c` — File handling in C, using `fopen`, `fclose`, `fprintf`, and `rewind`

## Topics covered
- Functions
- Mathematical problem-solving in C
- File handling (opening, writing to, and reading files)
- Input/output handling

## How to run
These programs were written and compiled using **Falcon C++**.

To run a file:
1. Open the `.c` file in Falcon C++
2. Compile
3. Run

Alternatively,(GCC, Clang, or an online compiler like OnlineGDB) can also be used.
